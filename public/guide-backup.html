手机照片自动备份 指引

把全家的手机照片自动备份到影音库（NAS），按设备分相册、互不混淆。以下方案按自动化程度排序，均为各品牌 NAS 通用。人在外地想远程访问家里的库？看《远程访问指引》。

方式一：网页一键增量备份（零安装，本系统内置）

半自动打开影音库网页 → 照片页 → 点「⬆️ 备份手机照片」。
① 首次使用：输入设备名（如 爸爸手机 / 妈妈手机）→ 照片库自动创建同名目录与相册。
② 选照片：安卓推荐选「允许浏览整个相册文件夹」，之后每次一键就完成对比与上传；iPhone 勾选照片后确认。
③ 自动增量：已备份过的照片（按 文件名+大小 比对）自动跳过，只传新照片，重复点击不会产生重复。
限制：浏览器关掉就停，所以每次需要打开网页点一下。想要"连上 WiFi 全自动"，看方式二/三。

方式二：安卓全自动（Round-Sync，配置一次终身不管）

推荐 · 全自动安卓手机装 Round-Sync，让它把「相机相册」定时同步到 NAS 的照片目录。
📱 App 在哪拿？装好影音库后，电脑桌面会生成「家庭影音-手机备份」文件夹， 双击里面的「下载手机备份App.bat」即自动下载；也可打开同目录的 《手机备份App-下载与设置说明.txt》按说明手动下载。

Round-Sync 是开源免费软件（GitHub 2300+ 星，GPL-3.0），无广告、不收集数据；底层用 rclone 引擎，支持 SMB / WebDAV / FTP / SFTP 及 40 多种网盘，任何品牌 NAS 都能用。

配置步骤

1. 确认 NAS 已开启 SMB 或 WebDAV（见下方「各品牌 NAS 开启文件服务」）。
2. Round-Sync → 点「+」新建连接 → 选 WebDAV（或 SMB）→ 地址填 http://NAS的IP:端口/（WebDAV 如 http://192.168.8.62:5005/）→ 填 NAS 账号密码 → 测试通过。
3. 新建同步任务：左侧选手机 DCIM/Camera，右侧选 NAS 照片目录下的设备子目录（如 照片/爸爸手机/，可先在网页端备份一次让它自动建好）。
4. 方向选「复制」（只上传不删除）→ 「计划」里启用定期同步 +「仅 Wi-Fi」+「充电时」。
5. 完成。以后在家连 WiFi 并充电时，新照片自动进 NAS，影音库自动扫描入库到「爸爸手机」相册。

方式三：iPhone（iOS「文件」App，系统自带，免费）

系统自带iPhone 不装任何第三方 App，用系统「文件」App 连接 NAS 的 WebDAV：
1. 打开「文件」App → 右上角「⋯」→「连接服务器」→ 填 http://NAS的IP:端口/（如 http://192.168.8.62:5005/）→ 填 NAS 账号密码（可选择记住密码）。
2. 进入照片目录下的设备子目录（如 照片/妈妈手机/，可先在网页端备份一次让它自动建好）。
3. 打开「照片」App 选中照片 → 分享 →「存储到文件」→ 选刚才的目录 → 完成。下次备份时「最近项目」里已传过的不会再传。
说明：iOS 系统不允许任何 App 在后台自动传相册（苹果限制，连 iCloud 也一样），所以 iPhone 是"打开即传"级别。想更省事可以装 PhotoSync（App Store 免费下载，自动传输为一次性内购）。

各品牌 NAS 开启文件服务（SMB / WebDAV）

品牌 / 系统开启方法默认端口
群晖 Synology（DSM 7）套件中心安装「WebDAV Server」→ 打开 → 勾选启用 HTTP/HTTPS 端口5005 / 5006
威联通 QNAP（QTS）App Center 搜索安装「WebDAV Server」官方应用 → 启用并设置端口权限8081 等
华硕 / 爱速（ASUSTOR）App Central 安装「WebDAV」类应用（如 WebDAV Server）视应用
绿联 / 极空间等新品在系统设置的「文件服务 / 远程访问」里查找 WebDAV 或 FTP 开关；没有的话可用 Docker 装 Alist（万能文件服务，自带 WebDAV）视应用
Windows 电脑当服务器不强制要 WebDAV：本系统网页备份即可用；也可用免费工具（如 wodWebDAV / RabbitFTP）开启自定

安全提示：WebDAV 请只在家庭内网使用（不要在路由器上把端口暴露到公网）；账号密码用 NAS 的强密码。

常见问题

备份后照片在哪里看？

影音库 → 相册 → 相簿标签页，会按设备名出现独立相册（爸爸手机 / 妈妈手机…），首页横滑区也会展示。

HEIC / HEIF 格式（iPhone 高效格式）传不上去？

网页备份方式暂不支持自动转码 HEIC。建议：① iPhone「设置 → 相机 → 格式」改为「兼容性最佳」（拍出来就是 JPEG）；② 或用 Round-Sync/PhotoSync 直接传原文件（影音库的 RAW/HEIC 原片归档支持查看内嵌预览）。

会不会重复备份？

不会。按「文件名 + 大小」比对，已备份过的自动跳过；同名不同内容的照片会自动加序号保存，不覆盖。

两台手机的照片会混吗？

不会。每台设备一个独立目录与相册，天然隔离。

儿童模式下能备份吗？

不能。儿童模式开启期间备份入口隐藏、接口锁定，退出儿童模式（需家长 PIN）后才可备份。
