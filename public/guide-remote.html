出门在外远程访问 指引

人在外面，手机/笔记本照样看家里 NAS 的电影、听歌、看照片。按"安全 + 省心"排序。
⚠️ 重要前提：本系统面向家庭内网设计，没有登录密码。所以： 不要在路由器上直接把端口转发到公网裸奔。用下面的组网方案，安全又省心。

方案一：Tailscale 组网（强烈推荐 · 免费且最安全）

推荐 · 零公网暴露原理：给家里 NAS 和你的手机发一个"虚拟局域网通行证"，走到哪都能像在家一样访问。
1. 注册 Tailscale 账号（login.tailscale.com，免费档全家够用）。
⚠️ 注册时请不要用 Gmail / Google 账号：手机端登录 Google 账号在国内常常连不上，会出现「登不上、一直转圈、授权失败」。推荐用 Microsoft（Outlook）账号、Apple ID 或 GitHub 账号，这些在国内手机上都能正常登录。另外，NAS、电脑、手机必须登录同一个账号，否则互相看不见。
2. 家里：NAS 若支持 Docker 可装 Tailscale 容器；装在常年开机的电脑上也可以（Windows 版双击即装）。登录同一账号。
3. 手机：应用商店装 Tailscale，登录同一账号，打开开关。
4. 完成。以后在外面打开浏览器访问 http://NAS的虚拟IP:8090（Tailscale 面板里能看到每台设备的虚拟 IP），所有功能原样可用。
ZeroTier 是同类替代品，任选其一。此方案不暴露任何公网端口，运营商换 IP、无公网 IP 都不影响。

方案二：NAS 官方云服务（零配置 · 速度一般）

省事 · 免费中转
· 威联通：myQNAPcloud（控制台 → 应用服务 → myQNAPcloud，注册并绑定设备，开启 DDNS / CloudLink）。
· 群晖：QuickConnect（控制面板 → QuickConnect，设置一个 ID）。
· 中转速度受限（看 4K 可能吃力，刷照片/听歌/看剧够用）。
注意：官方云地址同样把管理界面暴露到公网，请确保 NAS 系统保持更新、使用强密码。

方案三：内网穿透（有公网 VPS / 需要固定网址时）

进阶 · 需配登录保护frp（免费，自备一台云服务器）或花生壳（付费买流量）。把家里的 8090 映射到 VPS 上，得到固定访问地址。
此方案会把服务直接暴露到公网，必须先解决认证问题（当前版本无登录功能，建议等口令锁功能上线后再用此方案，或用 frp 自带 auth token + 只允许自己的设备 IP）。

方案对比

方案难度费用速度安全
Tailscale / ZeroTier装 App 登录免费接近内网直连最好（零暴露）
myQNAPcloud / QuickConnect最简单免费中转限速依赖 NAS 强密码
frp / 花生壳中等VPS 费用看 VPS 带宽需自行加认证
路由器端口转发中等免费跑满宽带不推荐（无认证裸奔）

常见问题

远程能做什么？不能做什么？

看片（支持直连的格式原样可用）、听歌、看照片、读书、电视直播都能用。大码率 4K 受上传带宽限制，建议远程看 1080p 或 Remux 版。

手机端 Tailscale 登不上 / 一直转圈怎么办？

九成是账号问题：用 Gmail（Google 账号）注册的账号，在国内手机上需要连上 Google 服务才能完成登录，多数情况会失败。解决办法是用 Microsoft（Outlook）、Apple ID 或 GitHub 账号重新注册一个，再让 NAS / 电脑 / 手机都登录这个新账号即可（免费，几分钟）。另外请确认三端登录的是同一个账号。

家里宽带没有公网 IP 影响吗？

用 Tailscale/ZeroTier 完全不影响（它们专为无公网 IP 设计）。即使光猫是运营商大内网（CGNAT），也能通过 NAT 打洞直连；极少数打洞失败的场景会自动走官方中继，速度稍慢但依然可用。

远程成员能看到我家 NAS 上的其它内容吗？

看不到。默认只暴露影音库这一个端口（如 http://虚拟IP:8090），未开启子网路由——家庭局域网里的其它设备完全不可见，NAS 的文件管理、SMB 共享、SSH、管理后台等端口都不在放行范围内。如需更严格的端口级白名单，可在 Tailscale 管理台 ACL 中只放行影音库端口。

手机上每次都要手动开 VPN 吗？

需要开着 Tailscale 的开关才能进私有网络（这是 VPN 隧道的特性），但可以设成自动。iPhone：打开 Tailscale → 点右上角头像 → VPN On Demand → 打开，建议「Wi-Fi = Do Nothing（在家用局域网直连，不用开）」「蜂窝 = Always（出门用流量自动连）」。安卓：Tailscale → 设置 → 打开「始终开启的 VPN」。Tailscale 只转发私有网络内部（100.x 网段）的流量，不影响正常上网、不额外耗流量。注意 iOS 同时只能有一个 VPN 应用启用「按需连接」，手机若装了其它 VPN/加速器会互相顶掉。

以后会有远程版登录功能吗？

在规划中（简单口令锁）。上线前请优先使用组网方案，不要端口转发裸奔。
